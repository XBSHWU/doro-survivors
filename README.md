《勝利女神：妮姬》Doro 主題的《吸血鬼倖存者》風格網頁割草生存遊戲！

- **9 種武器 × 9 種超武進化**：飛天橘子、Doro 迴旋橘陣、失樂園聖光、Doro 魔性音波、追蹤小 Doro、神聖橘子汁、**紅蓮妖刀斬**、**巨型橘子隕石**、**Doro 機槍砲台**
- **3 張特色戰場地圖與機關**：伊甸櫻花廣場（可打破橘子補給箱）、方舟霓虹都市（霓虹加速道）、失樂園雪原（冰霜凍結結晶）
- **4 場暴君 / 女王 Boss 戰**：掘墓者、**暴君級列車「亞爾特艾森 Mk.VI」**、囂嘈魔機、萊徹女王 ＋ **黃金橘子狂潮 2× 金幣事件** ＋ 無盡模式
- **系統強化**：NIKKE 全爆裂系統（FULL BURST）、**升級重骰（Reroll）與跳過回血**、**8 項成就領獎與 9 種超武配方圖鑑**、伊甸橘子永久強化商店、繁中 / EN 切換

## 操作方式

- `WASD` / 方向鍵 / 滑鼠或觸控拖曳：移動
- `Space`：發動全爆裂（FULL BURST）
- `1` / `2` / `3`：升級選卡快捷鍵
- `P` / `Esc`：暫停
- `M`：靜音

## 本機執行

純靜態 HTML5 網頁，無須編譯：

```bash
python3 -m http.server 8765
```

接著開啟瀏覽器前往 `http://localhost:8765`。
