# 🍊 DORO 倖存者 (Doro Survivors)

《勝利女神：妮姬》Doro 主題的《吸血鬼倖存者》風格網頁割草生存遊戲！

## 遊戲特色

- **3 種可選 Doro 角色**：經典 Doro、伊甸機甲 Doro、狂暴橘子 Doro
- **6 種武器 × 6 種超武進化**：飛天橘子、Doro 迴旋橘陣、失樂園聖光、Doro 魔性音波、追蹤小 Doro、神聖橘子汁
- **NIKKE 全爆裂系統（FULL BURST）**：滿能量按 `Space` 釋放 8 秒全爆裂與動畫特寫
- **3 場暴君 / 終極女王 Boss 戰** ＋ 寶箱開啟 ＋ 無盡模式
- **伊甸橘子永久強化商店** ＋ 繁中 / EN 切換 ＋ Web Audio 合成音效與 BGM

## 操作方式

- `WASD` / 方向鍵 / 滑鼠或觸控拖曳：移動
- `Space`：發動全爆裂（FULL BURST）
- `1` / `2` / `3`：升級選卡快捷鍵
- `P` / `Esc`：暫停
- `M`：靜音

## 本機執行

純靜態 HTML5 網頁，無須編譯：

```bash
python3 -m http.server 8765
```

接著開啟瀏覽器前往 `http://localhost:8765`。
